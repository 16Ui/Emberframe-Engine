# Software Renderer 第三课：三角形光栅化与重心坐标

本课解决两个连续问题：哪些像素中心位于三角形内部，以及内部像素怎样从三个顶点获得插值颜色。

对应源码：[samples/software_renderer/03_triangle/main.cpp](../../../samples/software_renderer/03_triangle/main.cpp)。

## 1. 输入与输出

| 字段 | 内容 |
|---|---|
| 输入 | 三个二维顶点位置、每个顶点的 RGB 颜色、Framebuffer |
| 计算 | 包围盒、边函数、内外判断、重心权重和颜色插值 |
| 输出 | 填充后的彩色三角形 |
| 本课不做 | 深度测试、透视校正、纹理、背面剔除和裁剪 |

## 2. 为什么先计算包围盒

一张 `512 × 512` 图片有 262,144 个像素。三角形通常只覆盖其中一部分。三个顶点 x/y 的最小值和最大值组成包围盒，光栅化只扫描这个矩形，并把范围限制在 Framebuffer 内。

包围盒只缩小候选范围，不负责判断像素是否真的在三角形内。

## 3. 边函数

对有向边 `A→B` 和待测点 `P`，源码计算二维叉积：

```text
edge(A, B, P) = (Bx-Ax)(Py-Ay) - (By-Ay)(Px-Ax)
```

结果的符号表示 P 位于有向边的哪一侧。一个点位于三角形内部时，它相对于三条边的符号一致：全部非负或全部非正。两种情况都接受，因此顺时针和逆时针顶点顺序都能绘制。

本课使用像素中心 `(x+0.5, y+0.5)` 做判断，因为整数 `(x, y)` 表示像素方格的左上角，而光栅化要判断该像素的采样位置。

## 4. 重心坐标

对三角形顶点 A、B、C，内部点 P 可以写成：

```text
P = αA + βB + γC
α + β + γ = 1
```

`α、β、γ` 是 P 相对于三个顶点的重心权重。源码用三个子三角形的有向面积除以总面积得到这些权重。

权重不仅能判断内外，还能插值顶点属性。例如三个权重为 `(0.2, 0.3, 0.5)` 时：

```text
像素颜色 = 0.2 × 顶点A颜色 + 0.3 × 顶点B颜色 + 0.5 × 顶点C颜色
```

三个顶点分别为红、蓝、绿，输出就会在三角形内部形成连续颜色过渡。

## 5. 构建与运行

```powershell
.\scripts\build-windows.ps1 -Config Release -Target emberframe_sr_03_triangle
.\bin\Release\emberframe_sr_03_triangle.exe
```

输出文件：

```text
bin/Release/triangle.ppm
```

### 查询一个像素的完整计算

查询三角形内部附近的像素：

```powershell
.\bin\Release\emberframe_sr_03_triangle.exe --probe 256 256
```

查询明显位于外部的像素：

```powershell
.\bin\Release\emberframe_sr_03_triangle.exe --probe 10 10
```

程序会打印像素中心、总有向面积、三条边函数和内外判断。内部像素还会打印归一化重心权重、三权重之和与插值颜色。

比较两个结果：外部点仍可计算边函数，但至少一个符号与其余不同，因此不会进入颜色插值；内部点的三个权重同号，除以总面积后权重之和为 1。

## 6. 限制与下一课

本课按提交顺序直接覆盖颜色。如果两个三角形重叠，后画的一定覆盖先画的，即使它在空间中更远。下一课会为每个像素增加深度数据来解决遮挡。

这里的颜色是屏幕空间线性插值；纹理坐标等属性在透视投影后还需要透视正确插值，那属于后续课程。
