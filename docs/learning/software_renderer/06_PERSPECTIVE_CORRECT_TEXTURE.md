# 第 6 课：纹理与透视正确插值

## 本课解决什么问题

A5 已经能把三维顶点投影到屏幕，但如果直接用屏幕重心坐标线性插值 UV，斜向远离相机的表面会出现纹理拉伸。本课并排绘制错误与正确结果，定位误差来自哪里。

| 项目 | 内容 |
|---|---|
| 输入 | 四边形三维顶点、每个顶点的 UV、投影后的 $w$、像素重心坐标 |
| 计算 | 左侧仿射插值；右侧插值 `uv/w` 和 `1/w` 后恢复 UV |
| 输出 | `perspective_texture.ppm`，左错右对 |
| 假设 | 三角形已经投影且没有跨越裁剪面，UV 位于 `[0,1]` |
| 限制 | 当前纹理是程序生成的棋盘格，只使用最近邻式离散颜色，没有过滤和 Mipmap |

## UV 和纹理采样分别是什么

UV 是表面上的二维连续坐标：$u$ 表示横向位置，$v$ 表示纵向位置。它只是数据，不是颜色。

纹理采样接收 UV，再到二维图像中选择或计算颜色。本课的 `sampleCheckerboard` 根据 UV 落入的方格返回蓝色或米白色。

```text
三角形顶点 UV → 像素 UV 插值 → 纹理采样 → 像素颜色
```

## 为什么普通线性插值会错

设屏幕像素对三个顶点的重心权重为 $\alpha,\beta,\gamma$，满足：

$$
\alpha+\beta+\gamma=1
$$

错误的仿射插值直接计算：

$$
uv_{affine}=\alpha uv_0+\beta uv_1+\gamma uv_2
$$

这相当于假设顶点属性在投影后的二维屏幕上均匀变化。但透视除法已经用每个顶点不同的 $w$ 改变了空间比例，所以该假设只在三个顶点深度相近时近似成立。

## 透视正确插值

先定义：

- $uv_i$：第 $i$ 个顶点的纹理坐标；
- $w_i$：第 $i$ 个顶点齐次裁剪坐标的第四分量；
- $q_i=1/w_i$：该顶点的倒数深度因子；
- $\alpha,\beta,\gamma$：当前像素的屏幕空间重心权重。

先插值 $uv/w$ 和 $1/w$：

$$
q=\alpha q_0+\beta q_1+\gamma q_2
$$

$$
uv'=\alpha uv_0q_0+\beta uv_1q_1+\gamma uv_2q_2
$$

最后恢复当前像素的 UV：

$$
uv=\frac{uv'}{q}
$$

### 最小数值例子

只看两个顶点，屏幕权重各为 $0.5$：

- 近顶点：$u_0=0,w_0=2$，所以 $q_0=0.5$；
- 远顶点：$u_1=1,w_1=5$，所以 $q_1=0.2$。

普通插值得到 $u=0.5$。透视正确插值得到：

$$
u=\frac{0.5\times0\times0.5+0.5\times1\times0.2}
        {0.5\times0.5+0.5\times0.2}
  =\frac{0.1}{0.35}\approx0.286
$$

当前屏幕中点对应的三维表面位置仍更靠近近顶点，因此正确的纹理坐标不是 $0.5$。

## 两张图应该观察什么

- 左图使用仿射插值：远近方格沿屏幕方向接近等距，两个三角形交界附近还可能出现方向变化；
- 右图使用透视正确插值：越远的方格在屏幕上越密，符合透视缩短；
- 中间红线只用于区分两个 Viewport，不参与算法。

## 必做修改与故障实验

### 修改实验

把远端两个顶点的 z 从 `-5.0F` 改成 `-8.0F`。运行前先判断左右两图差异会增大还是减小，并说明依据是三个顶点的 $w$ 差异。

### 故障实验

在正确分支中移除最后的 `/ denominator`。这时得到的是 `uv/w` 而不是 UV，采样会整体偏向纹理一角。

### 边界实验

把四个顶点 z 都设成同一个值。此时所有 $w$ 相同，公式中的公共因子会约掉，左右两种插值结果应接近一致。
