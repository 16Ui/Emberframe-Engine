## 最新：波纹、条带与接缝画质修复

本轮针对实际截图中的异常线条修复了渲染路径，并重新编译 Release。以下结果对应同一个新版主程序及 32 个一致的编译后 Shader，不沿用下方历史报告的旧程序结果。

最终版 SHA256：`C5D0C6884D83139FAA5A0E9452E020F95CFD19ED07A9E70CFE3CAC1B449BF7AF`。程序及 32 个 Shader 的逐文件哈希保存在最终验收 `summary.json`，高清捕获另存相同版本的 `version.json`。

### 修复内容与实际原因

1. **彩色房间墙外的亮线。** 面积光位于场景包围盒内部时，仅用包围盒角点拟合透视范围会漏掉接收区域。现在用实际变换后顶点及近平面交点拟合覆盖范围；两侧被墙遮住的地板探针可见性均为 0。
2. **倾斜表面和软阴影中的条带。** 用真正的三角形几何法线修正逐采样点的接收平面深度；PCSS 的遮挡判断与遮挡者实际距离不再混用。比较结果先双线性过滤，软阴影使用连续半径和固定圆盘采样，避免整数半径跳变。矩阴影也在生成查询统计前修正接收平面：平行面保留 SAT 快速查询，倾斜面使用 64 个固定圆盘样本，仍在 GPU 中完成。
3. **背光面及灯面上黑白交替的线条。** 避免将背向灯心的几何面向大半影核外推；双面材质的背面几何法线与着色法线统一翻转。面积灯自身位于中心阴影图近平面之前，先判断投影范围，避免浮点误差让灯面朝向判断交替变化。
4. **球体和导入模型的接缝。** 修正极点、接缝及退化三角形；材质工作室用 64×96 细分减小真实网格在明暗交界处的台阶，体积 GI 场景保留 32×48 网格，新增不超过 4096 三角形的预算断言。glTF 缺省切线和 OBJ 平滑切线改为角度加权聚合，隔离硬边、镜像 UV 与退化 UV。显式保留有效的源切线，不把不同切线图混为一组。
5. **透明裁剪边缘的采样线条。** 在 discard 和分支之前取得纹理导数，并用显式导数采样，避免头发、树叶边缘使用未定义的隐式导数。
6. **屏幕空间与时序不稳定。** SSR/SSGI 先细化跨越深度表面的区间，再检查厚度，减少粗步进漏交；GTAO 半径不因投影端点离屏而突然变化；历史重投影考虑斜面上历史纹素中心与当前采样点的位置差异。
7. **演示预设中的低清阴影。** 演示场景统一使用 1024 阴影分辨率，不再以 256 的默认配置掩盖算法画质。没有关闭阴影、强行增加环境光或自动改走 CPU 来获得“干净截图”。
8. **VSSM 弧形灰带和 MSM 墙面条纹。** 矩统计采用补偿求和；SAT 的高、低两部分分别保存，用补偿相减后再取平均，避免大前缀吞掉小区域的有效精度，不要求设备支持双精度。MSM 去除小方差处突然切为硬阴影的分支。VSSM 使用连续搜索半径，最终过滤核限制在遮挡者估计的搜索支持域内，避免多峰分布中不可靠的条件均值让局部查询突然变成全图查询。

### 画质边界

- Hard 阴影和较低阴影分辨率仍会有锯齿；这是有限采样现象，不代表输出分辨率失效。平滑着色与有限多边形的真实自阴影仍可能在掠射光角度下显示细小的 shadow terminator 台阶；增加材质球细分减小了它，但不是任意导入模型的通用几何重建。
- 矩形灯仍使用灯心的单张透视阴影图近似可见性，不是完整面积光可见性积分；单图视场有上限。VSM/VSSM/MSM 也保留各自的近似漏光限制。当前 VSSM 是有界核版本，极宽半影会被搜索预算截断；倾斜面的有限采样矩查询也不是任意大区域的精确积分。
- 低采样、关闭过滤的 SSGI 保留噪声用于算法对照。SVGF 可明显减少噪声，但会损失部分细节；TAA 不等于完整间接光降噪。屏幕外与被遮住的几何仍不在 SSR/SSGI 的输入中。
- 时序回归覆盖静态几何、相机运动和斜面；不能据此声称所有法线贴图、动画或遮挡变化都无拖影。当前历史平面预测仍以着色法线近似局部平面。
- 缺省切线生成不是 MikkTSpace 的完全复现；高保真法线贴图应随模型导出匹配的切线。
- 自动检查和关键帧截图不是逐按钮鼠标验收，原生文件选择器的实际交互缺口仍保留下方说明。

## 本次修复

1. 小缩放模型被整体丢弃。将绝对行列式阈值改为相对于坐标轴长度的退化判断，保留正常的毫米级资源，并验证两条渲染路径中的小缩放和镜像。
2. 小模型聚焦后仍只有几个像素。镜头距离和近远裁剪面现在跟随实际世界包围盒，不再假定模型至少有固定尺寸。
3. 部分树木、桥梁和房屋 OBJ 导入失败。跳过并报告零面积三角形，保留有效表面；无有效表面的文件仍报错，自交多边形检查没有被取消。
4. 大资源上传刚完成就截图或退出。自动捕获等待连续四帧就绪，使画面与已退休帧槽的绘制统计稳定，避免旧背景图和零统计被当作结果。
5. ToyCar 与 SheenChair 的兼容副本仍有不支持的多 UV 和材质需求。重新准备单 UV 兼容资源，保留主纹理、烘焙其 UV 变换，明确回退不兼容的贴图；逐项记录在 `SOURCE.json`。原始模型未改动，旧兼容副本保存在本轮证据目录中。
6. 导入检查过于宽松。现在除成功返回和源三角形数量外，还要求真实 GPU 可见对象非零、捕获画面有足够前景占比，并且没有验证层错误。

## 使用边界与待确认交互

- 模型导入主线是静态 GLB、glTF、OBJ。FBX、原始 VRM 和骨骼动画不属于当前直接支持范围；“所有文件”只是解除文件选择器的显示过滤，不会增加解码器。
- 动漫模型使用准备后的静态副本，不是完整 MToon、表情、骨骼或头发物理。ToyCar、SheenChair 的兼容副本也不是原始扩展材质的高保真复现。
- 没有逐一测试模型库全部 619 个 OBJ；46 项是 23 个明确样例的双路径检查。
- 实时灯光上限为 64 盏；GPU 体积 GI 要求方向光、最多 4096 个实例三角形，体积网格只支持 16³ 或 32³。超出支持范围应提示并保留可操作界面，不自动启动耗时 CPU 参考。
- 矩阵、旋转圆环求交、缩放、撤销重做有自动覆盖；实际鼠标拖拽旋转缩放、原生文件选择器的“所有文件”选项，以及演示按钮与返回原场景的逐按钮操作，仍需在可用的桌面会话中确认。
- 四段视频已完成编码与源帧抽查，但未据此声称 TAA、SVGF 在所有运动和遮挡条件下无拖影、无噪声。
