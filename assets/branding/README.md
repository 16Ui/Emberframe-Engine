# EmberFrame 应用图标

`emberframe-icon.png` 是内置图像生成服务制作的原始透明 PNG；`emberframe.ico` 是同一图像的 16/24/32/48/64/128/256 像素 Windows 格式转换。

设计：深灰圆角底、几何框架与暖色余烬，兼顾任务栏小尺寸识别。PNG 用于 SDL 窗口和内嵌标题栏，ICO 嵌入可执行文件。

生成提示词：

```text
Production Windows desktop application icon for EmberFrame, a C++ Vulkan rendering engine. One square application icon. A compact geometric ember/flame nested within an angular three-dimensional frame: the frame hints at a rendered cube and an E, with a warm orange-red ember as the focal point. Bold clean silhouette, balanced negative space, crisp edges, legible at small sizes. Near-black charcoal rounded-square tile, restrained subtle depth. Transparent outside the tile. No lettering, watermark, tiny lines, elaborate detail, or surrounding objects.
```
